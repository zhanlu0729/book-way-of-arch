# book-way-of-arch
架构的御变之道：实践者的思考

# 一、前言
---
现在想来，已经是2020年春季的事了。

虽说多年来一直活跃在业务及架构一线，自已所做的分享还是太有限了。公开的分享就更屈指可数了，2017年时做的一次：[《求取一份极致的简单：海量应用容器化改造之路》](https://mp.weixin.qq.com/s/ML8U9ve80v_CmYaC9E0NvQ)、2018也做过一次：[《求取一份极致的简单：全链路跟踪中间件探索之路》](),当时原计划在Dockone做一个系列的分享《求取一份极致的简单》，诸多种种，计划未能善终。其他的公开分享就比较片段了...

2024年伊始，有了将自已多年的架构思想付诸于笔端行动了，也就开始运笔《架构的御变之道：实践者的思考》。然而，世事难料，因为工作的变动，遗失了太多创作的灵感...

新年的一年到来，2025年继续践行这个最初未竟的计划，保持继续前进！

# 二、篇目章节
---
## 第一篇 道之所存
>此篇主要讨论架构方面的一个核心问题，架构的“御变之道”到底是什么的问题。

## 第二篇 庙算
>此篇主要述说己所素备，以及多年以来在架构实践之路上所思所悟的瞬间，也正是这些些许瞬间的捕获和堆积，触发了这许多深入的思考。

## 第三篇 门之所在
>此篇主要讨论进入“御变之道”的门在哪里，以及打开这扇门的钥匙是什么。当然，这一门的所在并非唯一，这只是笔者个人多年来探索出的其中一扇门而已。

## 第四篇 实践篇
>此篇主要探讨，在你找到御变之道”的门并且大踏步迈入之后，这一路上的之所见、之所做、之所感、之所思。当然，这一路走来，或泥泞不堪、或靳棘丛生、或荒无人烟（无人问津之处）、更或身陷囹圄、间或亦有坦途...

## 第五篇 杂篇
>这一部分主要探讨不易归类于前四部分的内容，我又深感这一部分的重要性与伟大，在此以记之。


# 三、参考书目
---
这套架构思想，更多的是站在巨人和前辈的肩上，结合了自已多年来的一线架构经验，站在软件架构的角度来谈哲学。

参考目录如下（部分）：
1. 《建筑的永恒之道》2002年，赵冰博士译
2. 《禅与摩托车维修艺术》2018年，张国辰译
3. 《架构之美：顶级业界专家解密软件设计之美》2010年，王海鹏等译
4. 《架构整洁之道》2018年，孙宇聪译
5. 《敏捷整洁之道：回归本源》2020年，申健等译
6. 《匠艺整洁之道：程序员的职业修养》2022年，韩磊译
7. 《架构即未来：现代企业可扩展的Web架构流程和组织原书第2版》2016年，陈斌译
